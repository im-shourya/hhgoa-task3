# Known Limitations

## 1. Reverse Search Coverage

A reverse-image-search provider may not index every website or social platform.

No result does not mean the content does not exist.

## 2. Platform Access

Some social platforms restrict:
- automated access
- image retrieval
- page content
- API usage

The project must operate within provider/platform rules.

## 3. Face Recognition

Performance can degrade due to:
- pose
- lighting
- blur
- occlusion
- age changes
- resolution
- compression
- demographic/model effects

## 4. Threshold

The face similarity threshold is model/configuration dependent.

A demo threshold must not be presented as universal forensic certainty.

## 5. Search vs Identity

Reverse-image search discovers related content; it does not itself identify a person.

## 6. Blockchain vs Truth

Blockchain preserves a fingerprint. It does not make the underlying post true.

## 7. Source Authenticity

A blockchain registration does not prove the social platform account was genuine at the time of observation.

## 8. Off-Chain Evidence

If the original evidence disappears from the web, the on-chain fingerprint can still exist, but independent verification requires access to the exact evidence or a trusted copy.

## 9. Metadata Volatility

Post pages can change. Therefore the evidence manifest should record exactly what was observed at registration time.

## 10. Testnet

Polygon Amoy is a testnet. It is suitable for demonstration, not production evidence anchoring.
