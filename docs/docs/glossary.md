# Glossary

**Embedding** — Numerical representation produced by a recognition model.

**Face detection** — Locating a face in an image.

**Face verification** — Comparing two face representations to estimate similarity.

**Reverse image search** — Searching for web pages/images related to an input image.

**Candidate** — A search result being evaluated.

**Evidence manifest** — Deterministic structured description of discovered evidence.

**SHA-256** — Cryptographic hash function producing a 256-bit digest.

**Fingerprint** — Hash used as a compact representation of exact data.

**Smart contract** — Blockchain-resident program.

**Transaction hash** — Identifier of a blockchain transaction.

**Block explorer** — Public interface for inspecting blockchain data.

**Testnet** — Blockchain network used for testing rather than production value.

**Tamper-evident** — Changes become detectable because the fingerprint no longer matches.
